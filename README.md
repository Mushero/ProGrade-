# 学生成绩管理系统(StudentGradeManagementSystem)

一款专为教师设计的轻量化、私密化成绩管理工具。支持学生名单的一键导入、成绩录入及学期末数据一键归档。

---

***开发者昵称***​ *:suwnd*

- **技术栈**:Vue3+FastAPI+SQLite+TailwindCSS
- **设计理念**:极简、高效、本地化存储，保护学生隐私。

---

## ✨核心功能

- **智能表格导入**:完美适配教学办公习惯，支持特定格式的Excel/CSV文件直接导入。
- **动态成绩管理**:支持按班级、学期进行学生信息的快速检索与成绩录入。
- **学期归档与恢复**:
- **数据导出**:支持将当前学期成绩导出为标准报表，方便打印归档。
- **数据库备份**:课程结束以后，通过备份生成的数据库文件，可在未来随时重新导入系统进行查看。
- **本地化部署**:无需联网，所有数据均存储在本地`students.db`中，安全可靠。

---

## 📊导入文件规范

为了确保系统能正确解析班级与学生信息，请确保您的导入表格符合以下结构：

|第一行|[班级名称](例如：刑侦2401班)|||
| :-------| :--| :-----| :---------|
|**第二行**|**序号**|**姓名**|**学号**|
|第三行|1|张三|20210001|
|第四行|2|李四|20210002|

> **提示**:系统会自动提取第一行的班级信息并创建对应分组，无需手动输入班级。

## 🚀快速开始

### 1.后端环境配置(Python)

```bash
#安装依赖
pip install fastapi uvicorn pandas openpyxl

#启动服务
uvicorn main:app --reload
```

### 2.**前端环境配置 (Vue)**

```bash
# 安装依赖
npm install

# 运行项目
npm run dev
```

## 💾 数据备份建议

本系统采用 **SQLite** 作为存储引擎。

1. ​**学期结束时**​: 点击系统内的“备份数据库”按钮，将生成的 `.db` 文件妥善保存。
2. ​**以后查阅时**: 只需在系统中点击“导入备份”，即可找回当年的所有班级与学生成绩记录。
